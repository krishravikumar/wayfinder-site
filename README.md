# wayfinder-site

Hosted static output for [wayfinder](https://github.com/krishravikumar/wayfinder) (private repo).
No source code lives here — this repo only holds the built app and the generated daily digest,
published via GitHub Pages by wayfinder's CI. Public because GitHub Pages needs a paid plan for
private repos; the real source, schema, and CI logic stay in the private repo.

- App: https://krishravikumar.github.io/wayfinder-site/
- Digest: https://krishravikumar.github.io/wayfinder-site/digest/
